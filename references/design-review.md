# 设计计划与画面复核

新建或整体改版时在现有章节骨架中记录以下决定；局部修订只复核受影响部分。计划是制作依据，不必新增客户可见章节，也不默认等待用户批准。

## 编码前

- 写清读者、当前材料的核心判断和要完成的阅读或决策任务；指出一个影响构图的具体事实、证据或约束。
- 在选定品牌内确定字体角色、主色用途、阅读轴与主视觉焦点。已有品牌和用户参考优先；不为追求新颖另换字体或色板。
- 为主要章节记录“关系 → 形式 → 理由”，说明证据应紧邻什么、顺序或边界如何表达。同类核验可保持一致布局，短页不必凑多种形式。
- 复杂首屏或关系图可先用简短 ASCII 草图标出主次、连接和移动阅读顺序；简单单栏无需机械画图。
- 复核：如果换掉标题和客户名后，布局仍无法反映材料的核心关系，检查是否漏掉了应突出或连接的内容。共用品牌结构本身成立；不要为差异制造装饰。

## 渲染后

1. 用整体截图检查首屏焦点、章节层次、证据与结论的距离，以及重复布局是否帮助比较。用正常阅读尺寸检查中文断行、图注、连接线、对齐和留白。
2. 检查移动画面与实际交互：阅读顺序、表格或图的可读性、键盘焦点、输入控件与低动态偏好。静态检查不能证明这些通过。
3. 删除不提供信息的眉题、章节数字、徽章、单词高亮、背景网格或包围框。保留帮助引用、分类、状态或边界识别的元素。
4. 修正后检查影响区域；共用样式变化复核所有受影响模块。CSS 优先修正原规则、作用域与断点，避免叠加补丁形成不可预测的覆盖。
5. 简要记录实际检查的文件、尺寸、问题与修正；没有截图或操作验证就明确标注，不以“看起来专业”或静态通过代替证据。
